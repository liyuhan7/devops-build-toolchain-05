# E8-E10 集成运行说明

## 代码归属

- services/mdfixer/mdfixer/teaching.py：B 组 MDFixer 的补丁计划、安全边界和隔离验证；services/mdfixer/Dockerfile 是专用教学镜像。
- scripts/e8e10/lab.py：E8/E9/E10 阶段编排、固定样例和受限 GCC 依赖观察。
- services/buildchecker/：修复后的上游重检依赖；本实验不修改 A 组检测器，也不维护第二份 BuildChecker。
- tests/e8e10/test_profile.py：原有 11 项教学回归测试，保留成员新增的边界测试。
- run_lab.py、Makefile 和 .github/workflows/e8e10.yml：B 组 MDFixer 镜像、运行入口和质量门禁。

本实现是课程限定的显式 Make 规则教学 profile。B 轨道输出的 fixed-md-report.json、candidate.patch 和 gate.json 是实验产物，不等同于 docs/interfaces/mdfixer.md 定义的生产 Job 与 Artifact，也不声称实现完整的 EChecker/MDFixer API。

## 运行

先在自己的克隆仓库设置本地数字学号，再从项目根目录运行：

~~~sh
git config --local user.name 241250105
make e8e10-build
make e8e10-test
python3 run_lab.py e8 --track B --out work/e8-B-241250105-001
python3 run_lab.py e9 --track B --out work/e9-B-241250105-001
python3 run_lab.py e10 --track B --out work/e10-B-241250105-001
~~~

A 轨道的旧对照命令仍可通过 --track A 运行；B 组交付只需 B 轨道。每次运行必须选择新的 work/ 子目录，保留已有证据。镜像来自 services/mdfixer/Dockerfile。B 轨道只补 MISSING，不自动删 REDUNDANT；E10 在隔离副本中验证构建、程序输出和重检。

原实验包目录已删除；统一使用项目根目录的 run_lab.py 与 tests/e8e10/。CI 在 MDFixer 镜像里运行回归测试及 B 轨道 E8/E9/E10，上传 work/ 证据；A 组 BuildChecker 有自己的独立工作流。
