baseline.json 和 incremental.json 的实际图、发现一致；reused=[main.o,helper.o]，refreshed=[]，gate.passed=true。

```text
work/echecker/extended/e8/evidence/result/buildchecker/trace/t.28:579: openat(AT_FDCWD, "config.h", O_RDONLY|O_NOCTTY) = 4
work/echecker/extended/e8/evidence/result/buildchecker/make-db.txt:1044: main.o: main.c unused.h
```
processes.json 记录 cc1 PID 28 的父进程 gcc PID 27，job_pid=27；结合 trace 中 GCC 的 -c main.c -o main.o 参数，把成功读取归属 main.o 作业。stat/access 或失败打开不单独作为边依据。完整进程表、实际图和声明图保存在 buildchecker/。
