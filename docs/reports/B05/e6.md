E5 选择 `context-driven`，理由是项目 README 要求 C 编译器与 GNU Make，`build-essential` 是 Debian 系完整构建工具链聚合包。候选来自 E5 保存的 Codex 回复，未改动原始候选；SHA-256 为 `e0f4635cceddf909b589f3662c42aa894d11cc41b5049a6ce2ba2b0b7993a978`。E5 项目输入哈希在 E6 中逐项核对。

首次 E6 在 `work/draft/e6/B05-20261103-attempt-01/` 用原始候选构建。基线成功复现 `MISSING_MAKE`，但候选构建在访问 `deb.debian.org` 下载 Debian 包索引时运行至 600 秒预算并退出 124。该轮 `result.json` 和构建日志均保留，未将网络超时记作候选修复失败或成功。
