# E3 范围与限制

本文件记录 E3 基线未覆盖的内容与失败记录，用于判断结论的适用边界。

## 未覆盖内容

| 项目 | 边界 |
|---|---|
| MDFixer 附录 | 固定输入只定义 Target 声明风格；Macro、Hybrid、Implicit 与无效候选拒绝恢复不属本基线，不计为通过 |
| 其他扩展 | strace 文件跟踪、Ruby acceptance、终端交互用例与 libco 版本核验不属本基线必做矩阵 |
| 工具输出 | 四个工具尚未实现，本基线不含 `TOOL_OUTPUT` 记录 |
| CI 覆盖 | `e3-baseline.yml` 执行材料检查与 C0 行为验证；其他样本由各自入口单独运行并保存记录 |
| 独立复跑 | C0、C2、MD/RD、DRAFT 有非作者复跑记录；C1 与 MDFixer 只有非作者审核记录，暂无非作者复跑记录 |
