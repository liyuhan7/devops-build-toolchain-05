## 读取证据

- `run.json`：输入版本、配置、环境、运行状态和检查结果。
- `observations.md`：实际观察摘要。
- `commands.json`：命令、工作目录、时间、退出码和输出位置。
- 原始日志目录使用逐命令的 `*.stdout.log`、`*.stderr.log`；独立复跑目录使用 `commands.log` 合并输出，字节索引保存在 `commands.json`，辅助文本和摘要保存在 `packed-evidence.json`。

独立复跑中的 Make 数据库输出标记为 `EXCERPT`，保留目标依赖规则以及全文摘要、长度和节选位置；其余命令输出完整保留。读取指定命令输出的方法见 [E3 汇总](../summary.md#环境命令与日志)。运行路径是证据身份的一部分，索引分类不改变原始记录及其引用。
